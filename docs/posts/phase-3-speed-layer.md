# Phase 3 — Speed Layer

I'm building Volt, an open-source, self-hostable Gmail client — the whole
pitch is "Superhuman, but you own it."

Superhuman's entire value prop is one thing: never touch the mouse. So
before adding a single AI feature, I made sure the base inbox could do
that.

Volt's inbox is now fully keyboard-operable — archive, reply, navigate
threads, command palette, snippets — no mouse required, start to finish.

It's a small phase on paper but it's the one that actually earns the
"fast email client" claim instead of just asserting it.

Next: BYO-AI-key summarize/draft/search, on top of this speed layer, never
underneath it.
